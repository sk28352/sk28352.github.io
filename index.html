About me

I like problems where a model has to be useful to a real person, not just score well on a benchmark. That has meant chatbots that cite the documents they answer from, emotion-aware responses for mental health conversations, and forecasts that support renewable energy planning.

My work spans three areas: language models and retrieval, classical and ensemble machine learning, and time-series forecasting. Across all of them, I care about comparing against honest baselines and being able to explain why a model made a decision.

Projects

Retrieval-augmented generation

Northeastern student support chatbot Team project

A chatbot that answers international students’ questions about visas, employment, billing, and more, using 41 official university documents across 8 categories. Every answer comes with the source PDFs it was drawn from, and everything runs locally, with no API keys and no student data leaving the machine.

LangChain, LLaMA 3.2 via Ollama, ChromaDB, nomic-embed-text, PyPDF, Streamlit

View code on GitHub
  1. IngestPDFs are parsed, split into overlapping chunks, and tagged by category
  2. Embed and storeChunks become vectors in a persistent ChromaDB store, so documents aren’t reprocessed
  3. RetrieveThe six closest chunks are found, filtered to the category the student picked
  4. Answer with sourcesLLaMA 3.2 at temperature 0.2 answers from that context and cites each source

  • Hybrid transformer mental health chatbot Team project

    An empathetic chatbot pipeline that detects how someone feels and what they need before responding. RoBERTa handles multi-label emotion detection, Sentence-BERT recognizes intent, and LLaMA 3 generates the reply. It was benchmarked against SVM, Naive Bayes, and LSTM baselines.

    RoBERTa, Sentence-BERT, LLaMA 3, Ollama, PyTorch

    View team repo on GitHub

    0.95emotion detection accuracy, with 0.85 intent classification accuracy

  • Wind turbine power forecasting

    Forecasting pipelines on meteorological and turbine data to predict power generation. I compared classical time-series models (ARIMA, SARIMA) against Prophet, LSTM, and a tuned gradient boosting model, then tested six regressors on turbine power output.

    ARIMA, SARIMA, Prophet, LSTM, scikit-learn, MLP

    View code on GitHub

    R² 0.99with an MLP regressor, at an RMSE of 1.58 kW

  • Explainable heart disease prediction

    Six classical and ensemble models compared on the UCI Heart Disease dataset, with SHAP, permutation importance, and partial dependence plots explaining which risk factors drive each prediction, down to individual patients.

    scikit-learn, Random Forest, AdaBoost, Voting and Bagging ensembles, SHAP

Publications

  • 2025

    Solar Power Output Prediction with AI: Leveraging Meta Learner Ensemble Stacked Regressor

    A stacked ensemble combining KNN, a deep neural network, LightGBM, and Random Forest under a meta-learner, tuned to capture non-linear relationships in solar output. It reached an R² of 0.68, improving forecasting reliability for renewable energy.

  • 2023

    Human Gait Recognition using Cross View Micro Gait Dataset with Light Weight MobileNet

    A new cross-view gait dataset, built from videos recorded at varying speeds and angles, and a lightweight MobileNet model for recognizing people by how they walk. MobileNet V2 reached 98.7% test accuracy, outperforming Inception V3, SVM, and decision tree baselines.
